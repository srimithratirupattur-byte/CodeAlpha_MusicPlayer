# CodeAlpha_MusicPlayer

An interactive music player built with HTML, CSS, and JavaScript. Developed as task for the CodeAlpha Frontend Development Internship.

## Features
- Play, pause, next, and previous controls
- Progress bar showing playback progress
- Volume control
- Song title, artist, and cover display
- Clean interface with a lavender theme

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html - main page
- style.css - styling
- script.js - player logic
- lavender-bg.jpg - background image
- covers/ - song cover images
- songs/ - audio files

## How to Run
1. Download or clone this repository.
2. Open index.html in any modern web browser.
3. Use the controls to play your music.
